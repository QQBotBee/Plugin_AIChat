# AI智能聊天 Bee 插件

这是一个面向 Bee 机器人框架的 AI 聊天插件。插件基于 Bee Go Plugin SDK 构建，最终交付为单个 Windows 32 位 DLL。

## 功能

- 好友私聊 AI 对话。
- 群聊 AI 对话，支持前缀触发和艾特触发。
- 按用户 ID 共享会话记忆，好友和群聊里的同一用户使用同一份上下文。
- 会话过长时自动压缩为记忆摘要。
- 支持消息中夹带图片标记，模型可同时查看单张或多张图片。
- AI 请求失败时返回友好错误提示，但失败轮次不会写入会话历史。
- 本地 HTTP 配置页用于修改接口类型、基础地址、Key、模型、系统提示词、代理、触发方式和启用范围。
- SOCKS5 代理可用性检测，检测 Google 和 Baidu 访问延迟。

## HTTP 配置服务

HTTP 服务只用于插件配置，不是 AI 对话运行的必要条件。插件收到好友或群聊消息时会自动初始化聊天运行时，不需要先打开设置窗口或启动 HTTP 服务。

设置窗口中的“启动HTTP服务”会启动本地配置页：

```text
http://127.0.0.1:8765/
```

配置页支持：

- 选择内置 OPENCODE 或 OpenAI 兼容自定义接口。
- 填写自定义接口的 base URL 和 API Key。
- 获取可用模型列表时，按当前填写的接口信息查询。
- 设置对话模型。
- 设置系统预设。
- 设置对话上限。
- 图片仅在内存中临时下载并转成 base64，单张原图上限 10MB。
- 设置 SOCKS5 代理，格式为 `127.0.0.1:1080`，不要填写 `socks5://` 前缀。
- 检测代理访问 Google 和 Baidu 的可用性与延迟。
- 设置群聊触发方式：前缀触发或艾特触发。
- 开关好友和群聊工作区。

## 默认配置

配置文件保存到 Bee 插件数据目录下的 `config.json`。

默认值：

| 配置项 | 默认值 |
| --- | --- |
| 接口类型 | `opencode` |
| 基础地址 | `https://opencode.ai/zen/v1` |
| API Key | 空 |
| HTTP 端口 | `8765` |
| 对话模型 | 空，需要在配置页设置 |
| 对话上限 | `80` |
| 群聊前缀 | `#` |
| 群聊触发方式 | 前缀触发 |
| 好友对话 | 启用 |
| 群聊对话 | 启用 |

模型为空时，插件会回复：

```text
请先设置对话大模型
```

## 对话触发

好友私聊不需要前缀，直接发送内容即可触发 AI 对话。

群聊默认使用 `#` 前缀：

```text
#你好
```

如果在配置页切换为艾特触发，则群聊中艾特机器人并附带问题即可触发：

```text
@机器人 你好
```

## 构建

环境要求：

- Windows 10/11
- Go 1.22 或更高版本
- Zig 已加入 `PATH`
- Windows CMD

构建默认 DLL：

```bat
build.bat
```

指定输出文件名：

```bat
build.bat AI智能聊天.dll
```

构建产物位于：

```text
build\AI智能聊天.dll
```

## 项目结构

```text
.
├── plugin_main.go      # 插件元数据、生命周期和消息入口
├── chat.go             # AI 对话编排、触发解析和运行时服务初始化
├── ai_client.go        # OpenAI 兼容接口客户端和 SOCKS5 代理支持
├── sessions.go         # 会话存储和记忆压缩
├── config.go           # 配置默认值、加载、保存和规范化
├── http_server.go      # 本地配置页、配置 API、模型列表和代理检测
├── settings.go         # Bee 设置窗口和 HTTP 服务控制
├── bee_sdk.go          # Bee API 封装
├── build.bat           # Windows 构建脚本
└── other/              # C 插件壳、Worker 运行时和构建元数据工具
```

## 开发检查

提交前建议运行：

```bat
go test ./...
go vet ./...
```

真实 Bee 环境中仍需手动验证：

- 插件加载、启用、禁用和卸载。
- 好友私聊和群聊消息触发。
- Markdown 回复发送。
- 设置窗口显示和 HTTP 配置服务启动/停止。
- 代理检测结果是否符合本机网络环境。

## 编码与发布注意事项

- 构建目标固定为 Windows/386。
- `build.bat` 必须保持 GBK/CP936 编码和 CRLF 换行。
- `other/BeePlugin.def` 必须保持 GBK 编码。
- 不要提交 `build/`、`temp/`、DLL、EXE、RES、LIB、PDB 等构建产物。
- 持久化数据应写入 `GetAppDataDir()` 返回的插件数据目录。
